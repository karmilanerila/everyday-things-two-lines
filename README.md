Line 1 explains one everyday thing — a sponge — to a 10-year-old in a single vivid sentence built on one analogy: a sponge is like a tiny apartment building where thousands of little water tenants squeeze into the rooms and stay until you squeeze the building and they all rush out at once. Line 2 says what that analogy maps (the holes hold water and release it when pressed) and what it leaves out (a sponge soaks water up by itself, while a real building never drinks).

## Run it

```sh
python3 main.py
```
